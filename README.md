# DSH TokenFree

Use your own DeepSeek Web account in DSH, locally.

TokenFree 是面向 DeepSeek Harness（DSH）的非官方本地插件，让用户通过自己的 DeepSeek 网页账号使用 DSH。

## 当前状态

项目正在开发中。本仓库目前仅包含初始项目说明和许可证，源码与安装指南将在准备就绪后提供，尚未发布可安装版本。

## 设计方向

- 本人单账号、本地运行，不提供公共代理或账号池。
- 保留 DSH 原生对话、工具授权与执行流程。
- 支持独立会话、流式输出及基于官网计量的上下文压缩。

本项目由社区独立维护，未经 DeepSeek 官方认可或背书。
