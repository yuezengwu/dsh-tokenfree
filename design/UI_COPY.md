# TokenFree 简版文案

2026-10-23 · 账号、DSH 和用量状态横排在同一行；所有操作按钮集中在标题右侧。表内的操作词对应标题按钮，不夹在状态正文中。

| 状态 | 账号行 | DSH 行 | 用量行 |
| --- | --- | --- | --- |
| 未连接 | 未连接 · 登录 | 登录后可使用 | 用量未知 |
| 登录中 | 等待官网登录 · 取消 | 登录后可使用 | 用量未知 |
| 已连接 | 已连接 · 退出 | 未启用 · 使用 | {C} tokens |
| 已启用 | 已连接 · 退出 | 已启用 | {C} tokens |
| 需要登录 | 需要重新登录 · 登录 | 暂不可用 | 用量未知 |
| 计量缺失 | 已连接 · 退出 | 已启用；50% 判断暂停 | 用量未知 |
| 自动压缩未配置 | 已连接 · 退出 | 已启用 | 自动压缩未配置 |
| 压缩中 | 已连接 · 退出 | 已启用 | 正在压缩上下文 |
| 摘要已存 | 已连接 · 退出 | 已启用 | 摘要已保存，准备续聊 |
| 恢复中 | 已连接 · 退出 | 正在恢复原回答 | 正在连接官网 |
| 待核实 | 已连接 · 退出 | 已暂停 | 原请求待核实 · 核实 |
| 核实中 | 已连接 · 退出 | 已暂停 | 正在核实原请求 |
| 仍不明确 | 已连接 · 退出 | 已暂停 | 仍待核实 · 再次核实 |
| 官网仍在生成 | 已连接 · 退出 | 已暂停 | 原请求仍在生成 · 停止并核实 |
| 停止待确认 | 已连接 · 退出 | 已暂停 | 正在确认官网停止 |
| 压缩失败 | 已连接 · 退出 | 已暂停 | 压缩失败，请手动压缩 |
| 官网外部改动 | 已连接 · 退出 | 已暂停 | 网页上下文已变化 · 按 DSH 重建 |
| 连接失败 | 连接暂不可用 · 重试 | 暂不可用 | 用量待更新 |
| 其他入口退出 | 已退出 · 登录 | 登录后可使用 | 用量未知 |

C 只用官网原值，缺 C 显示未知；B 优先取官网当前模式预算，读不到时用默认 890,880 并标明默认来源；50% 门槛为 ceil(B/2)。旧值不冒充当前值。“使用”的辅助文本说明当前会话与本配置默认的范围，保存结果未确认时写“会话已启用，默认待确认”，保存失败时写“会话已启用，默认未保存”。

仅在事实确认后显示“已连接”“已启用”“已停止”或“已保存”；错误原因和技术字段留在本地日志。普通正文、工具执行与停止不另造一套 UI。
