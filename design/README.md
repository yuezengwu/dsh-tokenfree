# TokenFree 单卡片设计

2026-10-23 · 评审稿。

[演示](tokenfree-ui.html)只保留一张卡片，分两行：

- 上行：左侧为官网链接 **chat.deepseek.com**；使用、核实、登录或退出等按钮在右侧，与地址垂直居中。
- 下行：**账号 · DSH · 用量**三组状态横向排列，变化时原位替换。

宽度随插件内容区，卡片约 96px 高。窄屏保持两行，状态文字过长时省略，完整值可通过辅助文本读取。演示状态选择仅供评审，正式界面不包含它。

演示仅提供未连接、已连接、待核实三个入口。使用会同时选择当前会话和本配置默认；核实不重新生成。用量直接显示“{C} tokens”；官网文件功能预算和 50% 自动压缩门槛放在悬停详情中，不表示余额或模型总窗口。详细过程保留在日志中。

静态演示使用虚构值；插件现已按该布局接入真实账号、原生选择和官网计量，正式界面没有演示选择器。
